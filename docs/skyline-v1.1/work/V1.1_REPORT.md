## Branchements prêts
- Wordmark : `brand.wordmarkSrc` dans `src/data/demo.ts`.
- Photos : remplacer `public/images/hero.jpg` et `experience.jpg` (ou chemins dans `demo.ts`), puis `PLACEHOLDER_PHOTOS = false` pour retirer l'étiquette.
- Polices : voir `public/fonts/README.md`.
